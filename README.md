# 特工67 (Agent 67)

一款用 **pygame** 编写的横版像素射击单机游戏。角色参考了《角色及动作设计》等概念稿的风格
（蓝发红白装甲的特工主角、牛仔机器人敌人、赛博朋克霓虹街景），所有精灵均由代码程序化生成，
**不依赖外部贴图**，可一键打包为可直接运行的 Windows 可执行文件。

## 运行

```bash
# 安装依赖
pip install -r requirements.txt

# 直接运行源码
python launcher.py
```

## 打包为 exe

```powershell
.\build_exe.ps1        # 或手动：
pyinstaller --noconfirm --onefile --windowed --name "特工67" --add-data "game_assets;game_assets" launcher.py
```

产物位于 `dist\特工67.exe`（单文件，含中文字体）。宽约 19MB。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 鼠标左键 或 J / Z | 普攻射击（发射子弹） |
| 鼠标右键 | 投掷道具（手榴弹 / 火箭弹，需先拾取弹药） |
| ← / → 或 A / D | 左右移动 |
| 空格 / W / ↑ | 跳跃（可跳上屋顶平台） |
| Q | 技能：召唤全屏轰炸机炮弹从天而降（冷却 10 秒） |
| E | 大招：切入武士刀近战形态（20 秒，起跳举刀→下砸→挥砍连击，击杀获得 3 秒护盾；冷却 15 秒） |
| Esc | 暂停 / 返回 |
| F11 | 切换全屏 |

主菜单可选「操作说明」查看按键。近战形态下，左键 / J / Z 为武士刀挥砍。

## 界面

- **主菜单**：开始游戏、继续游戏（有存档时）、操作说明、设置、退出。
- **设置**：全屏、难度（简单/普通/困难）、敌人强度（弱/普通/强）、音量、显示 FPS。
- **暂停**：继续、存档并退出、重新开始、返回主菜单。
- **结算**：再次挑战 / 返回主菜单，并记录最高分。

## 游戏内容

- **地图**：赛博朋克街景（远景楼群视差 + 沿街随机生成的建筑/房子：亮窗、霓虹招牌、店面、
  高低错落），随角色向右前进持续随机生成，部分低层建筑的屋顶可跳上并会刷出敌人。
- **敌人**：近战/远程两类，头顶带血条，攻击间隔 2 秒，普通敌人 2 颗心（攻击 2 次死亡），
  屏幕内同时最多 5 个；死亡有粒子死亡动画，受击有闪白与击退。具备**成长机制**：
  每击杀 10 个敌人，后续生成的敌人与 Boss 血量 ×1.5。
- **Boss**：每击杀 20 个小兵刷新一个 Boss（近战/远程交替，20 颗心）；上方 Boss 血条在
  该 Boss 被击破后消失，直到下一个 Boss 出现才再次显示。
- **肉鸽元素**：地图随机刷出可拾取的增益（攻击强化/急速/疾行/护盾/医疗包）与道具
  （手榴弹/火箭弹，用普攻投掷/发射）。
- **技能**：普攻射击、全屏轰炸技能、武士刀大招（20 秒近战连劈形态 + 击杀给盾增益）。

## 存档

设置（`settings.json`）与存档（`save.json`）保存在**游戏可执行文件所在目录**
（打包运行）或**项目根目录**（源码运行），保存最高分、统计与一份可"继续游戏"的对局快照。

## 目录结构

```
agent67/
 ├─ agent67/            # 游戏源码包
 │   ├─ main.py         # 入口
 │   ├─ game.py         # 主编排/状态机/玩法循环
 │   ├─ config.py       # 常量/难度/设置
 │   ├─ palette.py      # 配色
 │   ├─ sprites.py      # 程序化像素精灵
 │   ├─ world.py        # 地图生成与碰撞
 │   ├─ player.py       # 玩家
 │   ├─ enemies.py      # 敌人与 Boss
 │   ├─ projectiles.py  # 投射物
 │   ├─ pickups.py      # 拾取物
 │   ├─ effects.py      # 特效
 │   ├─ hud.py          # HUD
 │   ├─ ui.py           # 菜单
 │   ├─ fonts.py        # 中文字体加载
 │   └─ savegame.py     # 存档
 ├─ game_assets/font.ttf  # 打包使用的中文字体
 ├─ launcher.py           # 打包入口脚本
 ├─ build_exe.ps1         # 一键打包脚本
 └─ requirements.txt
```

## 素材说明

`E:\Software\work\游戏设计` 目录下的 PNG 为**概念设计稿**（白底、姿势不统一，不是按帧排好的精灵图）。
为保证自包含、便于打包与透明通道，本作采用程序化生成像素图来还原其视觉风格，而非直接切片使用。
